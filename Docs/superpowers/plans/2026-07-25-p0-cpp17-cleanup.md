# P0 C++17 / MFUTURE Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把工程语言标准口径落到 C++17,清理 `co_await` / `co_return` 误导注释,全量迁移 `MFUTURE(T)` 为 `SFutureResult<T>` 并删除宏。单 PR。

**Architecture:** 仅做口径不动运行时。先 CMake 改 17 → MFUTURE 迁移 → 宏删除;头文件 `co_*` 注释清出与迁移同步进行。每步 commit,每步 build 验编。

**Tech Stack:** C++17, CMake 3.x, MPromise/MFuture 已存在, SFutureResult 在 `Source/Common/Runtime/Async/MAsync.h`。

## Global Constraints

(从 spec `Docs/superpowers/specs/2026-07-25-cpp17-p0-cleanup.md` 复制)
- 范围:P0 单一阶段;不动运行时 / 状态机 / `MAsyncContext`
- CMake `CMAKE_CXX_STANDARD 17` + 编译器显式 `-std=c++17`(`CMakeLists.txt:6` 和 `:210`)
- MFUTURE 全量迁移为 `SFutureResult<T>`,然后删除宏
- `FunctionParser.h` 中 `MFUTURE(` 前缀解析保留 + `TODO` 注释(后续 PR 清)
- 不引入 co_await / co_return 业务路径
- 每任务 commit;最终 PR 推送前 `Scripts/verify_protocol.py` 应不变
- 全程中文说明(commit message 可英文)
