## 0. 一句话

把工程语言标准正式口径落到 **C++17**，清掉 `MAsync.h` 等头示例里 `co_await` / `co_return` 的误导注释，**全量迁移所有 `MFUTURE(T)` 调用点为 `SFutureResult<T>` 并删除宏**。**单 PR** 完成三件事，**不在本 PR 引入运行时 / 状态机 / `MAsyncContext`**——那是 P1–P4。

---

## 1. 范围 / 非范围

### 1.1 在本 PR

1. CMake 语言标准改 17，并同步所有 bootstrap / IDE / clangd 配置点。
2. 删除头文件示例注释里的 `co_await` / `co_return`，改为指向父 spec §7 的 `AWAIT` / `AWAIT_OK`。
3. grep 现有 `MFUTURE(...)` 调用面（10 个文件，含生成代码外的源码），全部改写为 `SFutureResult<T>`，然后删除 `MAsync.h` 里的 `#define MFUTURE(T) SFutureResult<T>`。

### 1.2 不在本 PR（明确推迟）

- `MAsyncContext` / `MLoopAsyncContext`（P1）
- RPC dispatch pending future 回包（§10.1；P1）
- `Get` 红线 assert / `LOG_FATAL`（§8.2；P1）
- `AWAIT` / `AWAIT_OK` / `MASYNC` 宏 + 状态机手写 Frame（P2）
- MHeaderTool 状态机生成（P3）
- `MAwait` deprecated 注释（F1.4 节；P4）

非范围写在这里是为了**保护本 PR 不被继续扩张**。任何新增功能 / 重构 / 清理应在后续 PR 单列。

> 迁移顺序：先全部改写，再删除宏。MHeaderTool 后续 PR 可移除对 `MFUTURE` 前缀的解析。

| 文件 | 估计处数 | 说明 |
|------|---------|------|

| `Source/Common/Net/Rpc/MRpcChannel.h` | 1-2 处返回类型 | 用 `SFutureResult<T>` |

| `Source/Common/Runtime/Event/MEventAwait.h` | 1 处 | 同上 |

| `Source/Servers/EchoService/EchoService.{h,cpp}` | 2-4 处 | handler 返回类型 |
| `Source/Tools/MHeaderTool/Parsing/FunctionParser.h` | 1-2 处 | 解析/生成代码中"接受 MFUTURE 前缀"—— **本 PR 保留**（让旧源码仍可解析），但加 TODO 注释（"MFUTURE removed in P0 cleanup; remove this prefix support in follow-up"），后续 PR 同步移除 |

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 现有代码有隐性 C++20 依赖（concept / spaceship / ranges 等） | 编译期会立即暴露；Step 3 后立刻 `cmake --build Build`；如有红灯，本 PR 增加补丁 commit 而不扩大范围 |
| FunctionParser 仍认 `MFUTURE` 前缀导致"假 async"语义 | 已确认本 PR 保留解析但加 TODO；后续清理 PR 再删 |
| 生成代码若悄悄带 `MFUTURE(...)`（MHeaderTool 输出） | `grep Build/Generated` 验证；若发现，跟进该 MHeaderTool 分支处理；本 PR 不动生成代码 |
| 单 PR 文件数触 10+ | 可接受；diff 主要为机械替换，单 review 即可 |
| cmake 标准同步到 IDE / clangd 未覆盖 | `cmake -B Build` 重新生成 `compile_commands.json`；确认 `.clangd` 中无 `-std=c++20` 覆盖 |
