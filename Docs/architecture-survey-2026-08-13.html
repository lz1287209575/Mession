2. 客户端调用全链路

统一 FunctionId 稳定哈希(FNV-1a 32 → 折叠 16 位)，反射 dispatch，无 MT 字节 envelope（[RequestId:8B][FunctionId:2B][Size:4B][Payload]）。

Fiber 限制点 (Windows)

Windows FNullFiberBackend:SupportsSuspendResume() == false；SwitchIn 第二次直接 throw runtime_error。
SuspendCurrentCommandUntil 在 Windows 走 FPlayerCommandError("fiber_backend_unsupported") 报错分支。
POSIX FPosixFiberBackend 完整 ucontext 支持 suspend/resume。
业务侧 MAwait / MAwaitOk / TPlayerCommandFuture 全部清除（grep 0 命中）。
